
# QuickBuy 🛒

QuickBuy is an e-commerce web application built using React and Vite. The goal of this project is to build an online shopping experience where users can explore products and search for items.

## 🚀 Technologies Used

- React – Building the user interface
- Vite – Development server and build tool
- JavaScript – Application logic
- HTML – Structuring the application
- CSS – Styling the application


## 📦 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/RajeshwariPadma/QuickBuy-e-com.git
```

### 2. Navigate to the project folder

```bash
cd quickbuy
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173`.
